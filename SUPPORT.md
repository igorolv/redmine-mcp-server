# Support

Use GitHub Issues for general questions, bugs, and feature requests.

Before opening an issue, check:

- the current `README.md` (tool catalogue, configuration, troubleshooting);
- existing open issues;
- your Java version (JDK 25+ is required);
- `REDMINE_URL` reachability and the validity of `REDMINE_API_KEY`;
- the Redmine server version — the compatibility baseline is Redmine 4.0.4.

Do not publish API keys, tokens, real production URLs, issue data dumps, or private project
names. If the problem is security-related, follow `SECURITY.md`.
